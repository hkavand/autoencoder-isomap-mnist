# MNIST Autoencoder & Manifold Learning

An unsupervised learning project using an Autoencoder to learn low-dimensional representations of handwritten digits.

## Overview

A neural network Autoencoder is trained on the MNIST dataset to encode high-dimensional images into a compact latent representation. ISOMAP is then applied to the latent space to visualize the structure of the learned representations.

## Technologies

Python, PyTorch, NumPy, Scikit-learn, Matplotlib

## Topics

Autoencoders · Representation Learning · Latent Space · MNIST · ISOMAP · Dimensionality Reduction
